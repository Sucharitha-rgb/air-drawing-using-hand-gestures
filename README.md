 Air Drawing using Hand Gestures ✋🎨

 📌 Description
This project allows users to draw in the air using hand gestures captured via webcam.

 🚀 Features
- Real-time hand tracking
- Draw on screen using finger movement
- Color selection using gestures
- Erase functionality

 🛠 Tech Stack
- Python
- OpenCV
- MediaPipe

 ▶️ How to Run
1. Install dependencies:
   pip install opencv-python mediapipe
2. Run:
   python main.py

🎯 Use Cases
- Virtual drawing
- Gesture-based UI
- Fun interactive apps
